# Скрипты для серой локации (Mockup_Gray)

1. `1_MockupTilemapBuilder.cs.txt` — собирает пол и предметы серой сцены из mockup-картинки как отдельные GameObject'ы.
2. `2_InteractionSceneSetup.cs.txt` — добавляет игрока, диалоговое окно и механику осмотра (E) в сцену.
3. `3_Interactable.cs.txt` — компонент "можно осмотреть" на объекте.
4. `4_InteractionManager.cs.txt` — логика поиска ближайшего объекта и открытия диалога, висит на игроке.
5. `5_DialogueUI.cs.txt` — управление UI-панелью диалога.

Оригиналы (актуальные, рабочие) лежат в `Assets/Editor/` (1, 2) и `Assets/Scripts/` (3, 4, 5) — это просто копии-листинги для чтения вне Unity.
